{{- if not .Values.masterKey.existingSecret.name }}

*** MASTER KEY ***
The master key in the Secret {{ include "bomcensus-manager.masterKeySecret" . }} encrypts the CA keys and every
stored credential. If it is lost, the PKI and the credentials are lost and
every agent and scanner has to enroll again. Back it up now:

  kubectl -n {{ $ns }} get secret {{ include "bomcensus-manager.masterKeySecret" . }} -o jsonpath='{.data.master-key}' | base64 -d

The Secret is kept by "helm uninstall" (helm.sh/resource-policy: keep);
a later install with the same release name uses it again.
{{- end }}
